# iTerm2

This repository does not install an iTerm2 Dynamic Profile. Dynamic Profiles
always create a separate profile entry and require a unique GUID; iTerm2 does
not use them to extend an existing profile in place. A Dynamic Profile can
inherit settings from a parent profile, but it remains a separate profile.

To change an existing profile without creating another entry, edit that
profile in iTerm2 Settings. Export only the settings you want to keep here as
documentation or a color preset; do not install it as a Dynamic Profile.

See [iTerm2 Dynamic Profiles documentation](https://iterm2.com/documentation-dynamic-profiles.html).
